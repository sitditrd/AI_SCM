첨부 Excel 양식 검증 결과
========================

기준 파일
- 터미널_선석배정현황_통합_20260812(2).xlsx

검증 방법
- 기준 파일의 13개 시트 데이터를 현재 Python 생성 함수에 다시 입력
- 동일한 출처 URL과 수집시각으로 통합 Excel 재생성
- XLSX 내부의 Excel 구성 파일을 비교

검증 결과
- xl/styles.xml 동일
- xl/workbook.xml 동일
- xl/worksheets/sheet1.xml ~ sheet13.xml 모두 동일
- 그 밖의 xl/ 하위 구성 파일 및 [Content_Types].xml 동일

반영된 핵심 형식
- 헤더 Arial 10pt 굵게, D9D9D9 배경, 가운데 정렬
- 본문 Arial 10pt, 세로 가운데 정렬
- 표 전체 999999 얇은 테두리
- 첫 행 고정 A2
- 자동 필터 없음, 기본 격자선 표시
- 열 너비 최대 표시폭 + 2, 최소 6
- 출처 행 Arial 9pt 기울임, 666666
- 데이터 마지막 행과 출처 행 사이 한 줄 공백

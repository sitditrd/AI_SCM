# 화물추적 선사 확장 로드맵 — 자사 물동량 기준

작성 2026-08-11 · 근거 데이터 `ELVIS_TWSC.FMS_MBL_MST`

## 0. 요약

지금 가동 중인 5개 선사는 **자사 컨테이너 물동량의 14.95%** 를 덮는다.
확장 순서는 "개발 난이도"가 아니라 **"물동량 대비 투입"** 으로 정한다.

| 단계 | 추가 대상 | 누적 커버리지 | 필요 조건 |
|---|---|---|---|
| 현재 | A등급 5사 | **14.95%** | — (완료) |
| 1차 | B등급 4사 | **38.19%** | API 키 발급(무료·사업자등록증) |
| 2차 | C등급 2사 | **45.33%** | 영업 담당자 계약 |
| 3차 | D등급 7사 | **70.65%** | 사무실 PC + Playwright 상주 |
| (제외) | E등급 4사 | 81.45% | 공개 추적 자체가 없음 |

**핵심 판단: 1차(B등급 4사)가 압도적으로 효율이 높다.** 코드 한 줄당 커버리지 증가가 가장 크고, 비용은 0원이며, 4사 중 3사(머스크·CMA·하파그)가 DCSA 표준이라 어댑터 1개로 처리된다.

## 1. 물동량 산정 기준

```sql
SELECT LINE_CD, COUNT(*)
  FROM ELVIS_TWSC.FMS_MBL_MST
 WHERE ONBD_YMD >= '20250101'
   AND CNTR_TYPE IN ('F','L')   -- FCL·LCL 만. 'B'(벌크) 제외
   AND LINE_CD IS NOT NULL
 GROUP BY LINE_CD
```

- 모집단 **119,631건** (2025-01-01 ~ 2026-08-11)
- `SHIP_TYPE` 은 D/C 두 값 모두 동일 선사가 나타나므로 해상/항공 구분이 **아니다**. 필터에 쓰면 안 된다.
- `CNTR_TYPE='B'` 1,725건은 벌크라 컨테이너 추적 대상이 아니므로 뺐다.
- 같은 선사가 대리점·서비스별로 복수 `LINE_CD` 를 갖는다. 합산하지 않으면 순위가 왜곡된다.
  - 하파그로이드 = `LHAPAG1` + `LHAPAG` + `LHAPAGT`
  - COSCO = `LCOSCO` + `LCO`
  - CMA CGM = `LCMA` + `LCNCL`(CNC Line)
  - ZIM = `LZIM01` + `LZIM`
- `LINE_NM` 은 오염 데이터가 섞여 있다(`LHDMU` 에 "주)", `LNMS` 에 "장금상선" 1건 등). **`LINE_CD` 를 기준으로 잡고 이름은 최빈값으로 봐야 한다.**

## 2. 등급 정의

| 등급 | 정의 | 개발 형태 | 운영비 |
|---|---|---|---|
| **A** | 인증 없는 공개 JSON 엔드포인트 | Edge Function 어댑터 | 0원 |
| **B** | 공식 개발자 포털 · 무료 티어 | Edge Function + 키 보관 | 0원 |
| **C** | 공식 API 존재하나 영업 통해서만 발급 | Edge Function + 계약 | 협의 |
| **D** | TLS 지문·IP 기반 봇 차단 | 사무실 PC Playwright + 실 Chrome | PC 상주 |
| **E** | 공개 추적 화면 자체가 없음 | 불가 (선사 직접 협의 외 없음) | — |

**상위 4사(흥아·장금·고려·양밍)만으로 23.27%** 다. 이 4사가 D등급 물량의 92% 라, 하위 3사는 후순위여도 된다.

차단은 URL 이 아니라 **TLS 지문 · 데이터센터 IP 계층**에서 걸린다. Deno Edge / curl 은 통과 못 하고, 회사 IP 의 실제 Chrome 은 통과한다. 우회 수단(지문 위조·프록시 로테이션)은 만들지 않는다 — 서비스 약관 위반이고, 상대가 갱신하면 바로 깨지므로 유지가 불가능하다.

→ 사무실 PC 에 Playwright + 실 Chrome 을 상주시키고, `scripts/collect_bl_watch.py` 와 같은 방식으로 Windows 스케줄러가 돌린다. **결과만 Supabase 로 올리는 구조라 Edge Function 은 손댈 필요 없다.**

### 롱테일 (18.55%)

선사코드 33종, 22,190건. 개별 비중이 모두 0.5% 미만이다. 자동 추적 대상에서 빼고, 화면에서는 **선사 공식 추적 페이지 딥링크 버튼**으로 처리하는 것이 맞다. 어댑터를 33개 만드는 비용이 얻는 것보다 크다.

## 4. 권장 실행 순서

1. **B등급 4사 키 신청** (담당자 업무 · 개발 아님)
   - 머스크 → HMM → CMA CGM → 하파그로이드 순. 물동량 순.
   - 동시에 **MSC 영업 접촉** — 단독 5.71% 라 키만 나오면 즉시 반영된다.
2. **DCSA 공용 어댑터 1개 개발** — 머스크·CMA·하파그 3사 동시 커버 (17.0%p)
3. **HMM 전용 어댑터** (6.3%p)
4. **D등급 상위 4사 Playwright 수집기** — 사무실 PC 상주 (23.3%p)
5. 롱테일은 딥링크로 마감

1~3번까지만 끝내도 **커버리지 14.95% → 44.5%** 가 된다. 코드 작업은 어댑터 2개다.

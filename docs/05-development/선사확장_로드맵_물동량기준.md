## 5. 실행 순서

1. **하파그로이드 신청** — 돈·계약·영업 접촉 없이 혼자 끝나는 유일한 선사. 어댑터도 이미 완료
2. **HMM 신청** — 국내 선사, 한국어 지원, 결제 입력란 없음
3. **머스크 신청** — 상품 선택만 주의(Track and Trace Plus). 어댑터 완료
4. **ZIM·MSC 신청** — MSC 는 계약 절차라 오래 걸리므로 병행
5. **HMM·ZIM·MSC 어댑터 개발** — 키 나오는 순서대로

머스크·하파그는 **키 등록 즉시 재배포 없이 실조회로 승격**된다(`ready()` 게이트).
1~3번만 완료해도 커버리지가 **14.95% → 33.03%** 가 된다.

## 6. 공통 리스크

무료로 확인된 5사 **전부** 약관에 유료화 권리를 유보하고 있다. 영구 무료를 계약으로
보장한 선사는 없다(머스크 License Terms 4조 · HMM 약관 제17조① · ZIM EULA 1.7 ·
하파그 §5.1).

**대응**: 선사에서 요금 관련 통지가 오면 **Supabase Secrets 에서 해당 키만 삭제**한다.
`ready()` 가 false 가 되어 즉시 딥링크로 되돌아가며, 비용 발생 전에 차단된다.

## 7. 물동량 재집계 방법

```sql
SELECT LINE_CD, COUNT(*)
  FROM ELVIS_TWSC.FMS_MBL_MST
 WHERE ONBD_YMD >= '20250101'
   AND CNTR_TYPE IN ('F','L')   -- FCL·LCL 만. 'B'(벌크) 제외
   AND LINE_CD IS NOT NULL
 GROUP BY LINE_CD ORDER BY 2 DESC
```

- `SHIP_TYPE` 은 D/C 두 값 모두 같은 선사가 나타나므로 **해상/항공 구분이 아니다.** 필터에 쓰면 안 된다.
- 같은 선사가 대리점·서비스별로 복수 `LINE_CD` 를 갖는다. **합산하지 않으면 순위가 왜곡된다**:
  하파그 = `LHAPAG1`+`LHAPAG`+`LHAPAGT` · COSCO = `LCOSCO`+`LCO` · CMA = `LCMA`+`LCNCL` · ZIM = `LZIM01`+`LZIM`
- `LINE_NM` 에 오염 데이터가 섞여 있다(`LHDMU` 에 "주)", `LNMS` 에 "장금상선" 1건 등).
  **`LINE_CD` 를 기준으로 잡고 이름은 최빈값으로 본다.**

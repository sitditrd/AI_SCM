## 1. 목적
MBL/HBL/AWB 번호 하나로 해상·항공 **수입 화물의 통관 진행 상태**를 조회한다.
데이터: 관세청 유니패스 화물통관진행정보 OpenAPI (백엔드 프록시 경유).

## 2. 레이아웃 (와이어)
```
[공통 헤더 — 화물 추적 활성]
[타이틀] 화물 추적 — 해상·항공 수입 통관 진행
[조회 카드]
  (MBL/AWB | HBL 토글칩) [B/L 번호 입력____________] [연도▾] [조회]
  ↳ AWB 자동 감지 힌트줄: "AWB 감지 (180 · 대한항공) — 항공사 추적 ↗"
[결과 영역]
  A. 키 미설정: 발급 절차 안내 + [유니패스 직접 조회↗] [항공사 AWB 추적↗]
  B. 정상: 요약 표(진행상태·선박명·선적/양륙항·중량 등)
          + 통관 진행 이력 타임라인(세로 노드: 처리구분·시각·장치장)
  C. 오류/무결과: 원문 메시지 + 연도 확인 안내
[공통 푸터]
```

## 3. 인터랙션 규칙
- AWB 패턴(3-8자리, 11숫자) 감지 시 항공사 프리픽스 매핑(180 KE, 988 OZ 등 10개) → 딥링크 노출, 조회는 MBL로 수행
- Enter 키 = 조회. 백엔드 미기동(file:// 실행) 시 안내 카드 표시
- 디자인 토큰: 기존 style.css(--brand-*, src-card, pipe-node, f-chip) 재사용 — 신규 컴포넌트 없음

## 4. 백엔드 (server.py)
- `GET /api/track?type=mbl|hbl&no=&year=` → 유니패스 XML 조회 → JSON 관대 변환(스키마 변화 대응)
- 인증키: 환경변수 `UNIPASS_API_KEY` (발급: 유니패스 로그인 → Open API 사용신청 → 화물통관진행정보)
- 키 미설정: `{needKey:true, guide}` — 프런트가 발급 안내 렌더 (실패가 아닌 안내 UX)
